4. PROPOSED ENHANCEMENT - POLICY EFFECTIVE DATE RESTRICTION

   CURRENT BEHAVIOR:
   ┌─────────────────────────────────────────────────────────────────┐
   │ System sets fromDate = Today - 2 years                         │
   │ No consideration of policy effective date                       │
   └─────────────────────────────────────────────────────────────────┘

   ENHANCED BEHAVIOR (Using Application Startup Object):
   ┌─────────────────────────────────────────────────────────────────┐
   │ 1. Calculate standard 2-year lookback: Today - 2 years         │
   │ 2. Extract policy effective dates from application_startup:     │
   │    • Parse readApplicationStartup.portalGroups[].policies[]     │
   │    • Get effectiveDatetimeBegin for each membership type       │
   │    • Filter by claimType (MED, DEN, PHAR, HEAR, SBH)          │
   │ 3. Apply business rule per policy type:                        │
   │    FOR EACH claimType in request:                              │
   │      policy_effective = membership.effectiveDatetimeBegin      │
   │      IF policy_effective > calculated_from_date THEN           │
   │         fromDate = policy_effective                            │
   │      ELSE                                                      │
   │         fromDate = calculated_from_date                        │
   │ 4. Use the most restrictive (latest) fromDate across types    │
   └─────────────────────────────────────────────────────────────────┘

6. BUSINESS IMPACT

   BEFORE: Claims may be retrieved from before policy was active
   AFTER: Claims search limited to actual policy coverage period
   
   BENEFIT: Ensures data accuracy and prevents display of pre-coverage claims

7. TECHNICAL IMPLEMENTATION WITH APPLICATION_STARTUP

   Data Structure Access:
   • application_startup.readApplicationStartup.portalGroups[0].policies[]
   • Each policy contains memberships[] array with effectiveDatetimeBegin
   • Policy types: Medical, Dental, Vision, Hearing, Pharmacy
   
   Implementation Logic:
   ```
   function getRestrictedFromDate(claimTypes, applicationStartup) {
     const twoYearsAgo = new Date();
     twoYearsAgo.setFullYear(twoYearsAgo.getFullYear() - 2);
     
     let mostRestrictiveDate = twoYearsAgo;
     
     claimTypes.forEach(claimType => {
       const policy = findPolicyByType(applicationStartup, claimType);
       if (policy && policy.memberships[0]) {
         const effectiveDate = new Date(policy.memberships[0].effectiveDatetimeBegin);
         if (effectiveDate > mostRestrictiveDate) {
           mostRestrictiveDate = effectiveDate;
         }
       }
     });
     
     return mostRestrictiveDate.toISOString();
   }
   ```
   
   Error Handling:
   • Graceful fallback to 2-year lookback if application_startup unavailable
   • Log warnings when policy effective dates cannot be determined
   • Maintain backward compatibility with existing date range logic
